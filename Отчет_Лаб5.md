# Задание 1

## Кэширующий Proxy для дроби

**Требуется:**

Создать кэширующую версию класса дроби с использованием структурного шаблона Proxy.

Необходимо реализовать:

- получение вещественного значения дроби;
- изменение числителя и знаменателя;
- сохранение вычисленного результата;
- повторное использование сохранённого результата;
- сброс кэша при изменении дроби.

**Алгоритм решения:**

1. Создать интерфейс FractionOperations.
2. Реализовать класс Fraction, который хранит числитель и знаменатель.
3. Добавить проверку знаменателя на нулевое значение.
4. Реализовать вычисление вещественного значения дроби.
5. Создать класс CachedFraction, реализующий тот же интерфейс.
6. Добавить поле для хранения вычисленного результата.
7. При первом обращении вычислять значение и сохранять его.
8. При повторном обращении возвращать сохранённое значение.
9. При изменении числителя или знаменателя сбрасывать кэш.
10. Продемонстрировать работу кэширующего заместителя.

**Используемые классы:**

- FractionOperations;
- Fraction;
- CachedFraction.

**Результат:**

При первом обращении к дроби выполняется вычисление. При повторном обращении используется сохранённое значение.

После изменения числителя или знаменателя кэш очищается, и значение вычисляется заново.

# Задание 2

## Подсчёт мяуканий с помощью Decorator

**Требуется:**

Реализовать подсчёт количества мяуканий объекта, не изменяя основную реализацию класса Cat.

Необходимо использовать структурный шаблон Decorator.

**Алгоритм решения:**

1. Создать интерфейс Meowable с методом meow().
2. Реализовать интерфейс в классе Cat.
3. Создать класс CountingMeowable, который также реализует Meowable.
4. Добавить в декоратор ссылку на исходный объект.
5. Создать счётчик количества мяуканий.
6. При вызове метода meow() сначала выполнять обычное мяуканье, затем увеличивать счётчик.
7. Создать сервис MeowService, принимающий список мяукающих объектов.
8. Проверить работу декоратора на одном коте, добавленном в список 50 раз.

**Используемые классы:**

- Meowable;
- Cat;
- CountingMeowable;
- MeowService.

**Результат:**

Кот Барсик мяукает 50 раз.

Декоратор CountingMeowable подсчитывает количество вызовов метода meow().

В конце программа выводит:

Кот мяукал раз: 50

При этом основной класс Cat не содержит счётчика и не изменяется для добавления дополнительного поведения.

# Задание 3

## Удаление соседних повторов в списке

**Требуется:**

Создать обработчик списка целых чисел, который удаляет повторяющиеся элементы, если они расположены подряд.

При этом одинаковые элементы, находящиеся в разных частях списка, должны сохраняться.

**Алгоритм решения:**

1. Создать класс ListProcessor.
2. Добавить поле для хранения исходного списка.
3. Создать метод removeConsecutiveDuplicates().
4. Создать новый список для результата.
5. Последовательно перебрать элементы исходного списка.
6. Сравнивать текущий элемент с последним элементом результирующего списка.
7. Если элементы отличаются, добавлять текущий элемент.
8. Вернуть полученный список.

**Пример:**

Исходный список:

[1, 1, 1, 2, 2, 3, 1, 1, 4, 4, 4]

Результат:

[1, 2, 3, 1, 4]

**Используемый класс:**

- ListProcessor.

# Задание 4

## Работа с Map — минимальные цены на сметану

**Требуется:**

Обработать информацию о магазинах, продающих сметану с различной жирностью.

Необходимо определить количество магазинов, в которых цена сметаны является минимальной для каждой категории жирности.

Рассматриваются три категории:

- 15%;
- 20%;
- 25%.

**Алгоритм решения:**

1. Создать класс SourCreamOffer для хранения информации о магазине.
2. Сохранить название фирмы, улицу, жирность и цену.
3. Создать класс SourCreamAnalyzer для обработки данных.
4. Считать информацию из файла sour_cream.txt.
5. Получить количество магазинов из первой строки файла.
6. Обработать записи о магазинах.
7. С помощью Map определить минимальную цену для каждой жирности.
8. Подсчитать количество магазинов, предлагающих сметану по минимальной цене.
9. Вывести три полученных значения в порядке жирности 15%, 20% и 25%.

**Используемые классы:**

- SourCreamOffer;
- SourCreamAnalyzer.

**Исходные данные:**

Файл sour_cream.txt содержит количество магазинов в первой строке, а затем информацию о каждом магазине.

Формат записи:

Название фирмы | Улица | Жирность | Цена

**Результат:**

Для исходных данных программа получает:

2 1 2

Это означает:

- для сметаны жирностью 15% минимальную цену предлагают 2 магазина;
- для сметаны жирностью 20% минимальную цену предлагает 1 магазин;
- для сметаны жирностью 25% минимальную цену предлагают 2 магазина.

# Задание 6

## Работа с Queue — проверка соседних элементов по кругу

**Требуется:**

Создать программу, проверяющую наличие одинаковых соседних элементов в очереди.

Очередь рассматривается как замкнутая последовательность, поэтому последний элемент также необходимо сравнить с первым.

**Алгоритм решения:**

1. Создать класс QueueChecker.
2. Добавить поле для хранения очереди.
3. Создать метод hasEqualNeighboursInCircle().
4. Перенести элементы очереди во временный список.
5. Последовательно перебрать элементы.
6. Сравнивать каждый элемент со следующим.
7. Для последнего элемента выполнить сравнение с первым.
8. Если найдена одинаковая пара, вернуть true.
9. Если одинаковых соседних элементов нет, вернуть false.

**Используемый класс:**

- QueueChecker.

**Результат:**

Проверяются две очереди.

Первая очередь:

[4, 7, 2, 2, 9, 1]

Результат:

true

Вторая очередь:

[4, 7, 2, 9, 1]

Результат:

false

## Stream API

### Задание 7.1. Создание ломаной из точек

**Требуется:**

Создать программу для обработки набора двумерных точек с использованием Stream API.

Необходимо:

- удалить повторяющиеся точки;
- отсортировать точки по координате X;
- преобразовать координату Y в положительное значение;
- создать объект ломаной.

**Алгоритм решения:**

1. Создать класс Point для хранения координат X и Y.
2. Переопределить методы equals() и hashCode() для сравнения точек.
3. Создать класс Line для представления линии между двумя точками.
4. Создать класс Polyline для хранения массива точек.
5. Создать исходный список точек.
6. Получить поток элементов с помощью stream().
7. Использовать distinct() для удаления повторений.
8. Использовать sorted() для сортировки по координате X.
9. Использовать map() для преобразования координаты Y с помощью Math.abs().
10. Преобразовать результат в массив.
11. Создать объект Polyline и вывести его.

**Используемые классы:**

- Point;
- Line;
- Polyline.

**Результат:**

Программа формирует ломаную из обработанных точек.

Полученная ломаная:

Линия [{1;2}, {1;3}, {2;5}, {2;6}, {3;4}, {4;1}]

5. Получить поток строк с помощью stream().
6. Преобразовать строки в объекты PersonNumber.
7. Удалить пустые и некорректные записи.
8. Исключить людей, у которых отсутствует номер.
